# Monan — Graphic Designer Portfolio

A responsive React + Vite portfolio based on the supplied screen recording's dark navy, electric-blue visual direction and portfolio sections.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. In the terminal, run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL Vite prints (usually `http://localhost:5173`).

To build for deployment, run `npm run build`.

## Personalize before publishing

Search `src/App.jsx` and replace:
- `Monan` with the designer's actual name/brand.
- Project titles, descriptions, and image URLs in the `projects` array with his real projects.
- Portrait URL in the About section with his own photo.
- `hello@monan.design` with his actual email address.
- Social profile URLs with his own links.

The project images and portrait currently use remote Unsplash placeholders. The contact form is a front-end demo: it displays a note but does not deliver submissions. Use the email link or connect a form service/backend before publishing.
